# Actodo

Actodo is a simple React-based to-do application that helps users manage their daily activities.

## Features
- User Sign Up and Login
- Add and Delete Activities
- Personalized Dashboard
- Responsive UI with Tailwind CSS
- Navigation using React Router

## Tech Stack
- React.js
- React Router DOM
- Tailwind CSS
